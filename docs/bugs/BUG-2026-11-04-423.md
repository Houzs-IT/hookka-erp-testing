## BUG-2026-11-04-423 — Service case photos could not be opened `service-cases` ✅

Owner 2026-11-04. Thumbnails linked to the photo with `target="_blank"`, but photos are stored as base64 data URLs and Chrome refuses a link from a page to a data URL, so the click did nothing. Fix: a click opens the photo in the page (`PhotosPanel`, previous / next / close). The cause is read from the code and known browser behaviour; the fix needs a check on a real case with photos.
