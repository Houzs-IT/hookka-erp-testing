## BUG-2026-11-10-HK0141 — Pending Delivery "Set Status" left the sofa's pillow out of the set `delivery` 🟡

🟡 **On branch** (`fix/hk-0141-sofa-set-counts-pillow` → `main`). Ticket HK-0141 (Violet, Management, 10 Nov 2026).

**Symptom.** In Delivery → Pending Delivery, a sofa set showed "3/3 Ship" while its pillow, packed with the last compartment (sticker 4/4), was still in production. The set could go on a DO without the pillow.

**Cause.** `buildReadyPlanning` (`src/lib/delivery-pipeline.ts`) counted a sales order's set from POs that have an UPHOLSTERY card. A pillow is an ACCESSORY PO routed FAB_CUT → FAB_SEW → PACKING with no UPHOLSTERY card, so it was skipped. The FG sticker already pairs it with the sofa (`src/pages/production/index.tsx`, `isPillowSticker`).

**Fix.** The tally also counts the SO's pillow POs (ACCESSORY + "pillow" in name/code, the sticker's rule); a pillow is ready when `poReadyForDelivery` would list it. Other accessories are unchanged. Regression: `tests/delivery-pipeline.test.mjs` ("HK-0141 …").
