## BUG-2026-11-22-542 — costing page flashes when picking another fabric tier `products` `costing` 🟢

- **Symptom:** on `/products/:id/costing`, clicking a different fabric tier (Lv1–Lv4) blanked the whole page to "Loading costing…" for a moment, then redrew it (owner, 2026-11-22: 「我点不一样level 会闪一下」).
- **Cause:** the tier is part of the fetch URL (`?tier=`); `useCachedJson` reseeds `data` to null on a URL change with no cache, and the page treated "no data" as "show the loading screen".
- **Fix:** the page keeps the last costing of the same product (matched by id or code) on screen while the new tier loads, dims it, and highlights the clicked tier at once.
- **Regression test:** `tests/costing-tier-no-flash.test.mjs`.
