## BUG-2026-11-24-551 — MRP froze on EXPAND: every order line drew every supplier `procurement` `mrp` `performance` 🟡

- **Symptom:** owner 2026-11-24 「MRP 很卡顿 / button 那些也是卡顿」. Measured on prod (read-only): EXPAND took 794 ms and grew the page from 3,448 to 42,528 DOM nodes — 474 supplier dropdowns holding 20,301 options. Every later click on the expanded page was slow.
- **Cause:** `src/pages/planning/mrp.tsx` rendered the full "Other suppliers (will be bound)" list (all suppliers) inside every short order line's `<select>`.
- **Fix (#1587):** a line lists its bound suppliers plus one "Other supplier…" option; picking it opens the full list for that line only (`OTHER_SUPPLIER`, `otherOpen`). Owner option 2 (any supplier, auto-bound on PO create) is unchanged. Same PR: "+N ROLL" sits on the PO Outstanding line so rows keep one height; the Warehouse filter is gone (one raw-material warehouse).
- **Regression test:** `tests/mrp-plan.test.mjs` ("EXPAND no longer draws every supplier…").
