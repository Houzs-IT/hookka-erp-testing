## BUG-2026-11-24-554 — Pending Delivery column filter only filtered the current 50-row page `delivery` `pending-delivery` 🟡

- **Symptom:** HK-0174 (Siti, 2026-11-24): with the overdue (Expected DO) filter on, page 1 showed 32 rows and page 2 another 5. Ticking page 2 replaced the page 1 ticks ("Create DO (5)"), so one DO for every overdue item had to be built page by page.
- **Cause:** `src/pages/delivery/index.tsx` hands the Planning / Pending Delivery grids one 50-row slice (`pageSlice`). A grid's column filter / sort only sees the rows it is handed. The slice was bypassed for the search box but not for column filters.
- **Fix:** the two PO grids report `onColumnViewChange`; while a column filter, sort or grouping is on, the slice is bypassed (whole list, pager hidden), the same as a search. Select-all then ticks every matching row.
- **Regression test:** `tests/delivery-list-filters.test.mjs` ("a column filter / sort spans the whole Planning + Pending Delivery list").
