## BUG-2026-11-27-584 — AI Connector rate limit bypassed by a JSON-RPC batch `mcp` 🟡

> **Last verified: 2026-11-27**

- **Report:** Weekly ERP R&D report 2026-11-27, finding #9.
- **Cause:** the limit counts `mcp_calls` rows, written after each call (`waitUntil`), and a batch had no size cap, so every call in one POST saw the same old count.
- **Fix:** at most 10 messages per POST; calls already made in this request are added to the count. Parallel POSTs can still each see the same count (not fixed here).
- **Regression test:** `tests/mcp-connector.test.mjs` (rate limit).
