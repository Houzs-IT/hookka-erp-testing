## BUG-2026-11-09-440 — A locked sales order's Edit button vanished with no reason `sales` `ui` 🟡

An IN_PRODUCTION sales order is locked for editing once any of its job cards leaves WAITING (`GET /api/sales-orders/:id/edit-eligibility` → `reason: "production_started"`, Option D rule 2026-05-06). The SO detail page only explained the older `production_window` reason, so for `production_started` the Edit button simply disappeared. The owner read it as "production has not started but I cannot edit" (2026-11-09) — the page gave no way to see which department held the order.

Fix: the page now shows the lock banner ("<department> job card is <status> …") and a disabled "Edit (locked)" button with the same text as its tooltip. The lock rule itself is unchanged; whether a BLOCKED job card should count as started is a separate owner decision.

Regression: `tests/so-edit-lock-reason.test.mjs`.
