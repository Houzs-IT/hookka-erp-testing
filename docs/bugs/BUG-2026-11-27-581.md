## BUG-2026-11-27-581 — AI Connector: open client registration accepted any https redirect host `mcp` `security` 🔴

> **Last verified: 2026-11-27**

- **Report:** Weekly ERP R&D report 2026-11-27, finding #1.
- **Cause:** `POST /api/mcp/oauth/register` needs no login and `validRedirectUri` (`src/api/lib/mcp-store.ts`) accepted any https host. A phishing link with a client named "Claude" sent the code to an outside host after one Allow click; the Allow page never showed the host.
- **Fix:** redirect hosts limited to claude.ai, claude.com, chatgpt.com and loopback, checked at register AND at authorize (so clients registered earlier stop working). The Allow page names the redirect host.
- **Regression test:** `tests/mcp-connector.test.mjs` (OAuth helpers; the Allow page).
