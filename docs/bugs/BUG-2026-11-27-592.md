## BUG-2026-11-27-592 — Bulk "Convert N to GRN" posted stock with no look at what it would receive `procurement` `grn` `inventory` 🟡

> **Last verified: 2026-11-27**

- **Found by:** the screen-map pass for the AI Connector guides.
- **Symptom:** ticking POs and pressing "Convert N to GRN" (desktop PO list) creates one GRN per PO for every line's outstanding quantity and PUTs it straight to POSTED (stock up, PO receivedQty, In Transit cleared). Desktop asked only "Create GRN for N POs and clear In Transit?"; the phone (`/m` Procurement, "→ GRN") asked nothing at all.
- **Fix (posting flow unchanged, owner brief):** a confirmation dialog first, listing each PO, each line (code, description) and the quantity that will be received AND posted to stock, with Cancel / Confirm. One plan, `src/lib/po-bulk-grn.ts` (`buildBulkGrnPlan`, `bulkGrnItems`), feeds both the dialog (`src/components/procurement/bulk-grn-confirm-body.tsx`) and the POST /api/grn bodies, so what is shown is what is posted. Same dialog on desktop and `/m`; on `/m` the POs are read first, nothing is written before Confirm.
- **Not changed:** the single-click posting itself (no arrival / QC step) — that is the owner's flow.
- **Regression test:** `tests/guide-bugs-2026-11-27.test.mjs` (592).
