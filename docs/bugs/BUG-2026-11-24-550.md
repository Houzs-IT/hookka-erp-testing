## BUG-2026-11-24-550 — Purchase Invoices detail export left UOM blank on every line `procurement` `export` 🟡

- **Symptom:** Purchase Invoices > Export (the per-line detail listing, `purchase-invoices-detail-*.xlsx`) had a UOM column, but it was empty on every row. Reported by a user on 2026-11-24.
- **Cause:** `buildPiDetailListingAoa` (`src/lib/doc-detail-listings.ts`) passed a hard-coded `uom: ""`. The data was already there: `GET /api/purchase-invoices/:id` returns each line's `uom` (set only when billed in a different unit, HK-0149) and `poUnit` (the PO line's unit, from `attachPoPrices`).
- **Fix:** UOM = `uom || poUnit || ""`, the same rule the PI detail page uses to show the unit.
- **Not affected:** the "Export CSV" button exports one row per PI with no line columns, so it has no UOM.
- **Still blank:** a PI line with no PO behind it has no unit to show (the detail page shows "-" for it too).
- **Regression test:** `tests/doc-detail-listings.test.mjs` ("PI detail: UOM is the billed unit, else the PO line's unit").
