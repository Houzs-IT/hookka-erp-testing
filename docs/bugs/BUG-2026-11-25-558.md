## BUG-2026-11-25-558 — AI Connector: whoami answered with a blank name `ai-connector` 🟡

> **Last verified: 2026-11-25**

- **Symptom:** the owner's first live Claude connect answered `whoami` with `"name": ""` (role SUPER_ADMIN, 108 modules — the rest was right).
- **First attempt (#1613) did not fix it:** reading `display_name` too and letting an empty string fall through still returned "" on prod, so the second `SELECT … FROM users` in whoami was not returning the row at all (cause of that not pinned down; `users.email` is NOT NULL, so a returned row could not be blank).
- **Fix:** whoami no longer runs its own query. `resolveAccessToken` already joins `users` to authenticate the token; it now also reads `display_name` and `email` on that same row and carries `name` on the identity.
- **Regression test:** none automated (needs a live adapter row); verified by calling `whoami` from the owner's connected Claude after deploy.
