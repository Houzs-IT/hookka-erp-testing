## BUG-2026-11-06-426 — Customer overdue sets showed "PO PO/2610-023" `dashboard` `ui` 🟡

🟡 **Fixed on branch** (`fix/overdue-sets-double-po`, to `main`).

**Symptom.** On the Sales tab's customer overdue sets list, an order row read `SO-2610-082  PO PO/2610-023  KL  due 2026-11-…`. The word PO appeared twice.

**Root cause.** `src/pages/dashboards/CustomerOverdueSetsCard.tsx` put a fixed `PO ` in front of the customer PO number (added in 8bad8769b). This customer's PO numbers already start with `PO/`.

**Fix.** The `PO ` label is added only when the customer PO number does not already start with "PO" (any case). Bare numbers such as `12345` still show as `PO 12345`.

**Regression.** None added: a one-line display change with no shared helper to test.
