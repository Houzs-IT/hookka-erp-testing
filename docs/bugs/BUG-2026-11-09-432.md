## BUG-2026-11-09-432 — Invoice search and filters stopped at 500 rows and Prev/Next did nothing `invoices` `pagination` 🟡

With a search or any filter set, the Invoices page asked `limit=2000` with no page number. The server clamps to 500, so matches past 500 never appeared, while the footer still showed the full match count and several pages; pressing Next changed the page number but fetched the same 500 rows. A search also dropped the status / customer / date filters.

Fix: search and filters combine and are paged server-side like the plain browse view (`page` + `limit`); a new search returns to page 1; the header shows the whole match count; the export uses the same combined query. Found while working the Houzs review list (owner 2026-11-08).

Regression: `tests/invoice-filter-paging.test.mjs`.
