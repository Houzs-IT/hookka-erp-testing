## BUG-2026-11-23-545 — Send Notification lists no workers and no ERP users `production` `notifications` 🟡

- **Symptom (owner, 2026-11-23, while testing HK-0170 on canary):** Production Overview → Send Notification → "Individual workers" or "ERP users" showed an empty list, so a notice could not be sent to one person.
- **Cause:** the dialog's loader `useEffect` depended on `depts.length`. Setting the departments re-ran the effect; its cleanup set `alive = false` while the same load was still reading the workers and ERP-user responses, so both lists were dropped.
- **Fix:** the loader runs once on open (`[]` deps).
- **Regression test:** `tests/send-order-notification-dialog.test.mjs`.
