## BUG-2026-11-27-583 — Product cost still sent by /api/products and /api/bom to every role `products` `bom` `rbac` 🟠

> **Last verified: 2026-11-27**

- **Report:** Weekly ERP R&D report 2026-11-27, finding #6.
- **Cause:** #1631 hid cost in the UI only. `stripSellingPrice` (`src/api/routes/products.ts`) removed selling-price fields, not `costPriceSen`; `GET /api/bom` and `/api/bom/:id` returned `labourCost` / `materialCost` / `totalCost` with no gate. The AI connector never loaded `product-costing:read`, so R&D could not see costs inside the costing module.
- **Fix:** cost fields removed (reads and the create / update / delete replies) unless `product-costing:read` or `cost-ledger:read` (the `requireCostingRead` gate); `product-costing:read` added to the connector's permission lookup.
- **Not fixed here:** `GET /api/inventory` `finishedProducts` still carries `costPriceSen`; stock adjustments (`src/pages/inventory/adjustments.tsx`, service-case returns) price their cost-ledger rows from it, so stripping it there needs a server-side cost lookup first.
- **Regression test:** `tests/cost-api-gate.test.mjs`.
