## BUG-2026-11-10-490 — cron workflows printed raw replies (money figures, invoice numbers) into public GitHub Actions logs `ci` `security` 🟡

The repo is public. Fifteen cron workflows ran `echo "Body: $body"` on the ERP's reply — `nightly-pi-gl-backfill.yml` prints `postedRm` and the failing invoice numbers — and `deploy-cron-worker.yml` printed the first 300 bytes of the heartbeat reply. Anyone could read them in the Actions tab. Sister: Houzs#5512 (H3 B6). What past logs exposed is not listed here; GitHub keeps Actions logs for 90 days by default.

Fix: every reply goes through `scripts/ci/log-safe-body.jq` — top-level keys, array lengths, booleans and count-like numbers only; figures, text and document numbers print as `<number>` / `<string>`.

Regression: `tests/workflow-log-hygiene.test.mjs`.
