## BUG-2026-11-05-424 — SKU Master table cells and headers were out of line `products` `ui` 🟡

🟡 **Fixed on branch** (`fix/products-table-align`, to `main`).

**Symptom.** On the Products SKU Master table some cells sat at the top of the row and others in the middle, the Variants "Configure" button stretched to the full row height, headers sat on the left above right-aligned numbers, the Fabric cell wrapped into three lines, Margin was cut off ("(94..."), and long product codes ran into the Description column.

**Root cause.** The row grid had no `align-items`, so block cells stayed at the top while flex cells stretched. The header style forced `text-left` on every column. Several column floors were too narrow for their content (Fabric 80px, Margin 120px, Code 120px).

**Fix.** `src/pages/products/index.tsx`: row grid gets `items-center` (sticky Code cell keeps `self-stretch` so its background still fills the row). Headers follow their column alignment from the column registry. Fabric shows the amount with the roll width on a second line, no wrapping. Wider floors for Code, Unit, Fabric, Margin and Labor %. Long codes truncate with the full code on hover.

**Regression.** None added: layout only.
