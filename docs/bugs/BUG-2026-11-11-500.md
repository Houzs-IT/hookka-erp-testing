## BUG-2026-11-11-500 — Stock Take page breadcrumb read "Inventory › Inventory" `inventory` `navigation` 🟢

🟡 **On branch** (`fix/stock-take-breadcrumb` → `main`).

**Symptom.** 11 Nov 2026, prod read-only check after #1324: the new Warehouse › Stock Take page (`/inventory/stock-take`) showed the breadcrumb "Inventory › Inventory". Stock Adjustments (`/inventory/adjustments`) had the same label.

**Cause.** `titleForPath` (`src/lib/route-titles.ts`) had no entry for either path, so it fell back to the first URL segment, "Inventory". The breadcrumb strip and the workspace tab strip both read that table.

**Fix.** Added "Stock Take" and "Stock Adjustments" to the table. Regression: `tests/stock-count.test.mjs` ("breadcrumb and workspace tab name the page").
