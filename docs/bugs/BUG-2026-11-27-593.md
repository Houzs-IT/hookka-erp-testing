## BUG-2026-11-27-593 — PO list right-click "Edit" was DRAFT-only, so almost always greyed out `procurement` `purchase-orders` 🟡

> **Last verified: 2026-11-27**

- **Found by:** the screen-map pass for the AI Connector guides.
- **Symptom:** the PO list's row menu "Edit" was enabled only for DRAFT, but manual POs are saved CONFIRMED, so it was disabled on nearly every row while the PO page's own Edit button allowed the edit.
- **Cause:** two rules. The detail page follows the owner ruling of 2026-08-07 (editable until goods land: not CANCELLED / RECEIVED / CLOSED, no POSTED / CONFIRMED GRN, nothing received); the list kept the old DRAFT-only rule.
- **Fix:** one shared helper, `src/lib/po-editable.ts` (`isPoEditable`, `hasReceivingGrn`), used by the list, the detail page and the phone PO page (`poActions`, `src/pages/m/lib/procurement-mobile.ts`, which had its own copy of the detail rule). The list GET's `grnRefs` (`src/lib/po-grn-refs.ts`) now carry each GRN's status so the list can apply the GRN lock without another read.
- **Regression test:** `tests/guide-bugs-2026-11-27.test.mjs` (593).
